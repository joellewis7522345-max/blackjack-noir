# Blackjack Noir

A single-page casino noir Blackjack PWA with a simplified Casual 21 default mode.

## GitHub Pages

Enable Pages for the `main` branch from the repository settings. The app opens from the repository Pages URL and can be installed:

- iPhone: open in Safari, then Share -> Add to Home Screen.
- PC: open in Edge or Chrome, then Install app.

## Modes

- Casual 21 is the default: bet, deal, hit, stand.
- Vegas Rules can be enabled in settings for double/split.
- Clean Mode hides chrome and leaves the table.
- Session Only avoids persistent saves on shared/school devices.

## Saves

The app autosaves locally unless Session Only is enabled. Settings include New Session and Privacy Wipe controls.
